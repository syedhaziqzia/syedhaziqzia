- 🎓 **Academics:** Pursuing BS in Computer Science at UoK with core interests in Data Structures, Database Architecture, and Distributed Systems.

- 🚀 **Civic Technology:** Actively engineering tech-driven solutions for public impact and urban problem-solving in Karachi.

> *A civic-tech initiative developed to empower citizens and streamline grievance reporting across Karachi.*

- 🧩 **Key Capabilities:**
